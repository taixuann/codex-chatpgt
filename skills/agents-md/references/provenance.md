# Provenance

This Skill is a minimal repository-local implementation of the admitted
follow-up from GitHub Issue #116. Its policy basis is the validated AGENTS
authoring/maintenance kernel in Issue #111 and merged PR #112 in
`taixuann/codex-chatpgt`.

No upstream Skill was copied: the current repository had no tracked,
discoverable `agents-md` Skill or equivalent `SKILL.md`; the remaining
`instruction-maintenance` material was runtime cache/non-discoverable content.
The implementation therefore uses
`CREATE_FROM_SCRATCH_WITH_JUSTIFICATION`, limited to a router, four focused
references, and one deterministic audit script. It does not claim that a
filesystem audit is native Codex runtime evidence.
