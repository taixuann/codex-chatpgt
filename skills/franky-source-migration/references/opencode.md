Inspect `AGENTS.md`, `.opencode/skills/`, `.opencode/commands/`, and the
selected OpenCode configuration. OpenCode can use configured instruction
patterns and discovers skills from `.opencode/skills/`.

Map instruction files and skills directly where semantics match Codex. Treat
OpenCode-specific agents, commands with model/provider settings, references,
plugins, and unsupported configuration as manual review.
