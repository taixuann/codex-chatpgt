# PI / program fit

Fit is a research bridge, not name replacement.

Evaluate:
1. applicant's supported scientific question/problem;
2. verified PI/lab questions, methods, or capabilities;
3. the concrete bridge;
4. why that environment enables the applicant's next research step.

Penalize:
- keyword matching;
- paper-title inventory;
- generic praise;
- changing only the PI name;
- new research identity introduced only in fit;
- claims based on stale or unverified PI information.

When fit is part of the requested artifact, `G07 PI_FACT_INTEGRITY` must pass. If current PI facts are unavailable, mark fit `not_assessed` or unresolved rather than fabricating specificity.
