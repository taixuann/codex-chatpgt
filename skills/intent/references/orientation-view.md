# Orientation projection

For non-trivial intent, project a concise review view with:

`STATUS`, `ORIGIN`, `WHY`, `CURRENT STATE`, `TARGET STATE`, `SCOPE`, `OUT OF
SCOPE`, `RELATIONSHIPS`, `CONSTRAINTS / DECISIONS`, `EVIDENCE STATE`, `OPEN
QUESTIONS`, and `READINESS`.

Use Mermaid only when it clarifies an evidence-backed relationship. The view
describes the problem and context; it must not prescribe file edits, task
ordering, implementation choices, or review actions.
