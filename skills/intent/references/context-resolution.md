# Context resolution

Classify each unresolved statement before asking a question:

| Uncertainty | First source |
| --- | --- |
| Current repository or implementation fact | anchored local repository |
| Durable Issue/PR state | canonical GitHub |
| Standard, platform, or external fact | targeted authoritative research |
| Preference, authority, priority, or trade-off | user |

Research should clarify the problem boundary. It must not silently prescribe
implementation. If local or canonical evidence answers a factual question, do
not ask the user to repeat it.
