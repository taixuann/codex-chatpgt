# GitHub Issue audit

Issue intake preserves the canonical repository and issue locator, title/body,
state, labels, material comments, observed time, and any linked PRs/branches.
The Issue is claimed intent, not unquestioned truth.

Audit only surfaces bounded by the Issue claims. Check problem validity, scope,
acceptance quality, current repository state, stale assumptions, and authority
gaps. When material, inspect duplicate, overlap, dependency, parent/child, and
supersession relationships plus partial PR resolution. Record absent or
conflicting evidence as `UNKNOWN` or a blocker rather than filling the gap.

Do not edit, assign, close, or comment on the Issue as an intake side effect.
