# INSTALL

INSTALL is recognized for an existing source skill that is not installed in the target environment. It is route-only in this campaign.

Resolve source → verify immutable ref/license → inspect package closure → check target placement/collisions → choose COPY, EDITABLE, or supported runtime install → adapt only compatibility details → validate links/dependencies → record provenance and clean temporary workspace.

If installation would redesign actions, workflow ownership, evaluation, or material behavior, route to CREATE or UPDATE. Do not claim INSTALL qualification here.
