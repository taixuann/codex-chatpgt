# AUDIT

AUDIT is read-only. It may assess behavioral evaluation, authoring/package quality, routing, ownership/placement, provenance/upstream drift, necessity, cost, or full lifecycle fitness. It returns one recommendation/disposition and does not apply it.

Use references/evaluation.md for behavioral evidence and references/review.md for diagnostic review. Keep Issue authority, criteria manifests, exact snapshots, and parent acceptance outside caller-supplied references. Missing runtime or source evidence is NOT_ASSESSED.

Typical dispositions are HEALTHY, UPDATE_NEEDED, LOCALIZE, MERGE, DISABLE_IMPLICIT, RETIRE, REJECT, or BLOCKED. A recommended UPDATE_NEEDED is not an authorized mutation. This campaign routes AUDIT but does not qualify it.
