# Argus skill standardization

Argus remains a non-canonical, read-only context-acquisition adapter. The
visible capability surface is exactly `codebase-reconnaissance`,
`research-source-discovery`, and `reference-state-reconnaissance`, sharing an
internal reconnaissance kernel. Each profile must state positive/oblique
triggers, negative and sibling-collision boundaries, narrow-scope behavior,
provenance/evidence anchors, no-mutation/no-role-drift rules, complete output,
and `NOT_ASSESSED` runtime limits.

Acceptance requires structural validation, catalog/repertoire/contract
reconciliation, packet validation, and independent parent/Athena review before
canonical acceptance. External source revisions or licenses not observable in
the current runtime remain unresolved.
