# Objective

Prove the narrow external scientific-evidence capability consumed by #16 without duplicating OpenScience or the broader research lifecycle.

# Activation gate

Activate only when a real #16/project task requires new external evidence and the #2/#6 context/review boundaries are stable enough to reuse.

# Reconnaissance

Inventory the actual OpenScience/external research interfaces, provenance returned, tool boundaries, failure modes, and what Feynman/direct reasoning already handles adequately.

# Execution phases

1. Select one real research question from #16.
2. Decide direct/Feynman vs external OpenScience routing using explicit criteria.
3. Acquire only relevant evidence.
4. Return a compact evidence packet preserving source, scope/conditions, disagreement, gaps, and uncertainty.
5. Hand the packet back to #16 for synthesis; do not promote it directly to Wiki/claims.
6. Compare value/cost against direct reasoning and document runtime limitations.

# Validation

- provenance resolves to actual sources;
- uncertainty/conflicts are preserved;
- no OpenScience subsystem is copied into this repo;
- #16 can consume the packet without duplicate orchestration;
- parent retains final interpretation authority.

# Stop conditions

Stop/simplify if direct reasoning is sufficient, external tooling returns unverifiable provenance, or the proposed adapter duplicates an existing interface.

# Definition of done

One real research task demonstrates correct evidence routing and a bounded return contract that strengthens #16 without becoming a second research workflow.
