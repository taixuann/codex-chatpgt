# Objective

Prove the shared Research and Knowledge workflow on one real research task while reusing existing Literature Wiki, Personal Wiki, RAG/BM25, OpenScience, project evidence, and Typst surfaces rather than rebuilding them.

# Activation gate

Before implementation, select one representative research/project question and inventory the actual existing interfaces/locations/contracts for:

- Literature Wiki;
- Personal Wiki;
- RAG/BM25 or hybrid retrieval;
- OpenScience/external evidence;
- relevant project/repository evidence;
- Typst/manuscript output if the task reaches writing.

Do not invent replacement infrastructure before this inventory.

# Target spine

```text
objective/question
-> retrieve/orient
-> understanding
-> sourced claims
-> evidence alignment/comparison
-> gap/conflict
-> hypothesis or research decision
-> prediction/test/analysis
-> result/interpretation
-> synthesis/promotion
-> academic output when needed
```

# Execution phases

1. Define one explicit objective/question and expected research decision.
2. Route sources: internal Wiki/Personal Wiki, RAG/BM25, project evidence, and #7 only if new external scientific evidence is needed.
3. Build conceptual understanding separately from sourced claims and personal hypotheses.
4. Create one useful claim set with provenance, scope/conditions, uncertainty, and counterevidence where applicable.
5. Compare literature using explicit project-selected dimensions; identify a meaningful gap/conflict/limitation.
6. Translate one gap/claim set into a falsifiable hypothesis or actionable research decision with prediction/test/weakening condition.
7. Where real result evidence exists, keep raw result -> analysis -> validation -> interpretation -> claim candidate -> promotion distinct.
8. Generate an academic-output outline/draft only from reviewed claims/evidence; Typst remains rendering/output, not knowledge authority.
9. Prove one compact project overlay instead of copying the global workflow.

# Validation

- retrieval is objective-driven rather than generic summarization;
- sourced claims and personal hypotheses remain distinct;
- provenance resolves;
- structured comparison produces an actionable gap/conflict/decision;
- hypothesis links to discriminating test/analysis;
- result promotion is explicit where exercised;
- project overlay remains minimal;
- existing RAG/OpenScience/Wiki/Typst systems are reused rather than wrapped gratuitously.

# Stop conditions

Stop/simplify if the selected task does not need every stage. Do not force hypothesis, experiment, or manuscript output when the research objective ends earlier. Do not create universal materials schemas from one pilot.

# Definition of done

One real research path shows that the shared spine improves scientific reasoning and knowledge reuse with minimal glue, while existing research infrastructure remains authoritative for its own responsibilities.
